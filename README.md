# Physio Path

Live app: https://mrshahameer.github.io/Physio-Path/

A 56-day recovery protocol tracker with daily quests, XP and levels.

## What's new
- Flare mode: one tap switches the day to a calm-down plan. Warns after 3 flare days.
- TENS tapers by phase, in line with NICE guidance.
- Daily pain fact (pain science education).
- Research check with sources in the Plan tab. Medication evidence notes in Life.
- Cloud sync with Supabase. Tap the cloud button in the header.
- Same login and database as the hair and face tracker.
- Score and "XP missed" in the header. Missed quests on past days cost score.
- Home screen icon when added to a phone.

## Setup
Run `setup.sql` once in Supabase (skip it if you already ran it for the hair app). Then paste the Project URL and anon key into Cloud sync, and sign in.
